## 사용 규칙

- Archive 문서는 근거 추적용으로만 본다.
- 최신 구현 여부는 코드와 CURRENT 문서를 기준으로 다시 확인한다.
- Archive에 있는 API 표를 그대로 구현 기준으로 사용하지 않는다.
